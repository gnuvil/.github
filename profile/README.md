## 👋 소개

그누빌(Gnuvil)은 **GNU + Village**에서 출발한 이름으로, 컴퓨터와 IT에 관심 있는 사람들이 함께 배우고 만들어가는 한국외국어대학교 중앙동아리입니다.

전공이나 개발 경험에 관계없이 누구나 참여할 수 있습니다. 각자의 관심사를 나누고, 자유롭게 협업하며, 작은 아이디어도 직접 구현해 보는 공간을 지향합니다.

## 🛠 주요 활동

- 💻 **프로젝트 개발** — 개인·팀 프로젝트, 아이디어 구현 및 서비스 개발
- 📚 **스터디** — 프로그래밍 언어, 컴퓨터 과학, 알고리즘, 웹 개발 등
- 🖥️ **인프라와 오픈소스** — Linux, 서버·네트워크, 가상화·컨테이너, 오픈소스 탐구
- 🤝 **커뮤니티** — 프로젝트 공유, 기술 이야기, 세미나 및 자유로운 교류

## 🚀 프로젝트

그누빌에서 진행한 프로젝트와 활동 결과물을 이곳에 차근차근 소개할 예정입니다.
