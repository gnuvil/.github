# Gnuvil

한국외국어대학교 소프트웨어 중앙동아리

그누빌(GNU + Village)은 컴퓨터와 소프트웨어에 관심 있는 사람들이 모인 동아리입니다.

서버를 직접 운영하고, 필요한 프로그램을 만들고, 공부한 내용을 서로 공유합니다. 처음 프로그래밍을 시작하는 사람부터 자신만의 프로젝트를 만드는 사람까지 함께 활동하고 있습니다.

# What we do

## Study

프로그래밍 기초부터 CS, 알고리즘, 백엔드 개발까지 관심사에 따라 스터디를 운영합니다.

## Build

동아리방에서 사용할 도구를 만들거나, 각자 관심 있는 주제로 프로젝트를 진행합니다.

## Self-host

직접 서버와 네트워크를 구성하고 운영합니다. Linux, 가상화, 컨테이너 등 다양한 인프라 기술을 실습하고 있습니다.
