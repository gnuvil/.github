## 📁 구성

- [`profile/README.md`](profile/README.md) — [Organization 메인 페이지](https://github.com/gnuvil)에 표시되는 소개

소개나 공통 안내를 개선하고 싶다면 변경 사항을 제안해 주세요. 프로젝트별 개발 문서와 코드는 각 프로젝트 저장소에서 관리합니다.
